# 検出点の事例

地図や写真で見て、分かったことの記録。外すための個別リストではない。

## 谷地川(35.69222, 139.33133)— 誤検出、仕組みでは外せていない

- 分類: 立体(記入あり)
- 現実: 本流にトンネルが2つ流れ込んでいる。交差ではなく、立体交差でもない
- データ:
  - way 326218009(谷地川、`waterway=river`)と way 326228293(谷地川、`waterway=river`、`tunnel=yes`、`layer=-1`)の線が、ノードを共有せずに交わっている
  - 326228293 の流れは、326218015 → 326234676(`tunnel=yes`)→ 326234674 と続き、326234674 が 326218009 の途中のノード 702983988 で終わる(合流)
- 検出された理由: 線が交わり、片方に `tunnel` があり `layer` も違うため
- 分かったこと:
  - `tunnel` / `layer` はその way が地下にあることを示すだけで、相手の下を通ることは示さない
  - 交点では線の左右が入れ替わっていて、交点のまわりの形からは誤検出と見分けられない
  - 「下流で相手に流れ込むか」は交差かどうかと関係ないので、判定に使えない
- 確認: 2026-11-01、航空写真とユーザーの確認
