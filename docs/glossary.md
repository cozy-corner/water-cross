# 用語

このリポジトリの文書・説明・コメントでは、次の意味でだけ使う。ここにない言葉で説明が要るときは、先にここへ足してから使う。

## 調べたいもの(現実の話)

| 言葉 | 意味 |
|---|---|
| 交差 | 別々の2つの水の流れが、互いを横切ること。上下に分かれていても、同じ高さでもよい。この調査が探しているもの |
| 合流 | 2つ以上の流れが1つになること。交差ではない |
| 分流 | 1つの流れが2つ以上に分かれること。交差ではない |
| 暗渠 | 地下に埋められているか、ふたがされていて、水面が見えない水路(下の出典)。水路そのものを指す名詞で、「何かの下をくぐる」という位置関係や動作の意味では使わない。データから暗渠かどうかは判断せず、タグはタグ名のまま書く |

道路と水路が交わる場所は、この調査の対象外。

## データの言葉(OSM の話)

| 言葉 | 意味 |
|---|---|
| 水路 | OSM で `waterway` が `river` `stream` `canal` `drain` `tidal_channel` のどれかの way。`ditch` は対象外 |
| way / ノード | OSM の線と点。説明では ID を添える |
| 共有ノード | 2本以上の水路の way が通る同じノード |
| 入る線 / 出る線 | 水路は流れる向きに描く決まりなので、way の終点に着く線を入る線、始点から出る線を出る線と呼ぶ。途中のノードでは入る線1・出る線1 |
| 交点 | 2本の線が地図上で重なる点。交差とは限らない |
| タグ | `tunnel=culvert`、`layer=-1` のように、タグ名と値をそのまま書く。日本語に置き換えない |
| 下を通るように描かれている | `tunnel` / `bridge` / `layer` から読める上下の関係。現実に下をくぐっているかは別 |

## プログラムの出力の言葉

| 言葉 | 意味 |
|---|---|
| 検出点 | プログラムが交差の候補として出した点。交差かどうかは確かめていない |
| 共有ノード(分類) | 検出点のうち、共有ノードで入る線2・出る線2のもの |
| 立体(記入あり)(分類) | 検出点のうち、ノードを共有せず線が交わり、どちらかに `tunnel` / `bridge` があるか `layer` が違うもの |
| 立体(記入なし)(分類) | 検出点のうち、ノードを共有せず線が交わり、上下を示すタグがないもの |
| 誤検出 | 地図・航空写真・現地で見て、交差ではなかった検出点 |

分類の名前はデータの形を表すだけで、現実の立体交差を意味しない。

## 出典

暗渠(コトバンク「暗渠」 https://kotobank.jp/word/暗渠 、2026-11-01 確認):

- デジタル大辞泉: 「地下に埋設したり、ふたをかけたりした水路。」
- 精選版 日本国語大辞典: 「道路、鉄道などの地下に埋設したり、地表にあっても水面が見えないように、ふたがしてあったりする通水路や排水溝。」
- 百科事典マイペディア: 「地下に埋設された，あるいは地表にあっても蓋(ふた)をした導水路。」
